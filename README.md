## TP de groupe Bootstrap

Un de vos amis vous contact pour que vous lui fassiez un site pour son entreprise. 

### Visuel du site :
Le site doit être entièrement dédié à la gloire des bananes. Oui, vous avez bien lu ! Nous voulons des images de bananes partout : en arrière-plan, dans les boutons, même dans les icônes de navigation.
Les couleurs dominantes doivent être le jaune (pour les bananes) et le marron (pour les peaux de banane). Si vous pouvez intégrer des nuances de vert (pour les feuilles de bananier), c’est encore mieux.
Une page de contact.
Le site doit avoir des boutons bananes.
Le site doit avoir un footer carrousel.
La police d'écriture la plus utilisée doit être à base de banane.
Le logo du site doit se trouver au centre du site, pour la gloire de la banane !
